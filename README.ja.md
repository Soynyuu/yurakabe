# ゆらかべ · Yurakabe

**壁紙に、ちょっと動きを。**

手持ちの動画をMacの壁紙・ロック画面で無音再生する、MITライセンスの小さなアプリです。「ゆらゆら」＋「壁」で、ゆらかべ。

## できること

- デスクトップとロック画面の両方で動画を再生
- ロック画面だけ動画にして、デスクトップは単色
- 両方を単色に切り替え
- 単色の色を変更
- 動画全体を縦横比を保って表示し、余白は黒帯
- ローカルのMOV・MP4を取り込み。尺の短縮・再エンコードなし

「静止」は単色です。任意の静止画像への切り替えは未対応です。音声は再生しません。動画素材は同梱しません。

## 現在の状態

**実験的なソース公開版**です。macOS 26以降が対象。Apple silicon・macOS 27・Xcode 26.6で開発しています。[Phosphene](https://github.com/kageroumado/phosphene)を基に、macOSの非公開の壁紙APIを使っています。OS更新で動かなくなる可能性があり、Appleの公認APIや公証済み配布アプリではありません。

元の試作品では、本物のロック画面で動画が動き、解除後に単色へ戻ることを手動確認しました。汎用版はビルドと自動テストを実施していますが、スリープ復帰、繰り返しのロック・解除、最終的な表示範囲の修正は実機での目視検証が残っています。

## ビルドと使い方

macOS 26以降、フル版Xcode 26.6以降、Gitが必要です。

```sh
git clone https://github.com/Soynyuu/yurakabe.git
cd yurakabe
./scripts/test.sh
./scripts/build.sh
```

1. `build/Build/Products/Release/Yurakabe.app`をFinderで「アプリケーション」にコピーし、起動します。
2. **Add Video…**で動画を取り込みます。
3. **Open Wallpaper Settings…**を押し、システム設定の「壁紙」→「Yurakabe」で動画を選びます。
4. アプリで再生モードと単色を選びます。複数ディスプレイ・Spaceへの割り当てはシステム設定で行います。
5. Control＋Command＋Qでロックし、解除後の表示も確認します。

ビルドスクリプトはローカル署名まで行いますが、インストールや壁紙の適用はしません。配布用のDeveloper ID署名・公証とは異なるため、ダウンロードしたアプリはGatekeeperにブロックされる場合があります。現段階ではソースからビルドしてください。

動画はH.264／HEVCに対応。回転情報付き動画は取り込み時に拒否します。スマートフォンの動画は必要に応じて回転を映像自体に反映して書き出してください。まずは通常の正方形ピクセル・SDR・1080p/30fpsを推奨します。HDRや特殊なアスペクト比は未検証です。

アプリはスクリーンセーバーの選択を変更しません。macOS側で壁紙とスクリーンセーバーを連動させる設定を選んだ場合は、元のスクリーンセーバーを選び直してください。

## 元に戻す・削除する

1. システム設定の「壁紙」で、Yurakabeを使っている全ディスプレイ・Spaceを元の壁紙や色へ戻します。
2. スクリーンセーバーを手動で変更していた場合は、元のものを選びます。
3. **Show Menu at Login**をオフにしてアプリを終了し、アプリをゴミ箱へ移動します。
4. 不要なら `~/Library/Containers/io.github.soynyuu.yurakabe.extension` を削除します。取り込んだコピーや設定が消えます。元動画は消えません。

適用前に元の壁紙の選択を控えてください。元の設定の自動バックアップ・自動復元機能はありません。メニューを終了するだけでは壁紙は停止しません。

## 負荷とプライバシー

動画再生には電力・CPU/GPU・メモリを使います。負荷ゼロは保証できません。ロック画面のみのモードでは、デスクトップでの再生を停止し、短い待機後に読み取り処理を解放します。

動画は端末内にコピーされ、通信・アカウント・解析送信はありません。ログには動画名やパスが含まれる場合があるため、Issueへ添付する前に確認してください。
